# 280Ah储能电池舱热管理仿真平台 v5：节能优先双预测MPC（保留空调）

## 本版调整原因
此前版本双预测MPC的空调预测介入阈值偏低，导致空调在温度风险尚不高时提前运行，空调累计能耗和系统累计能耗都可能高于固定送风组。本版重构MPC能耗分配逻辑。

## 三组控制策略
1. 固定送风组：固定风机转速和风阀开度；最高温度达到40℃后启用空调。
2. 固定阈值组：只根据当前温度和温差分段调节风机、空调和风阀。
3. 双预测MPC组：综合电池温度趋势、PCM液相率、环境温度、负荷倍率和分区温差。风机承担基础排热；预测风险接近高温区时才调用空调，空调最大负荷比例限制为0.25；风机和空调设置变化率约束。

## v5 默认MPC控制参数
- 风机基础指令：0.30
- 环境温度前馈系数：0.03
- 负荷倍率前馈系数：0.08
- 预测风险风机补偿系数：0.04
- 温差风机补偿系数：0.10
- 空调预测介入阈值：39.5℃（风险指标）
- 空调比例增益：0.04
- 空调最大负荷比例：0.25

说明：39.5℃是模型内部的预测风险介入阈值，不是电池安全温度限值，也不代表实际电芯允许温度。

## 48 h模型验证
验证工况与结果见 `three_scenario_validation_v5.csv`：
- 默认工况：环境30℃、1C；
- 高温工况：环境35℃、1C；
- 高负荷工况：环境30℃、1.2C；
- 极端高温工况：环境40℃、1C。

以上四个测试工况下，双预测MPC最终系统总能耗均低于固定送风组和固定阈值组；最大温差均不超过3℃。在35℃及40℃环境工况中，MPC会调用空调，但累计空调能耗低于两个对照组。

## 温度约束提示
35℃及40℃环境下，当前简化模型的MPC最高温度仍可能超过38℃目标。因此，v5证明的是当前模型设定下的相对节能效果和温差控制效果，不代表已满足所有工况的绝对温度约束。若要同时满足最高温度约束，需要进一步核验空调制冷量、风量分配、PCM热耦合参数及模型热源，并以CFD或实验校准。

## 重要说明
本平台输出是简化分区热模型的仿真结果，不是实测数据或CFD结果。不得将模型输出表述为实测节能率。对外说明书应明确仿真边界条件、设备参数和模型假设。
