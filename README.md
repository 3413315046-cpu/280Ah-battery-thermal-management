# 280Ah储能电池舱热管理平台 v6：滚动预测设备协同优化（保留空调）

## 本版核心改动
不再采用“风机低功率+空调持续补偿”的单一策略。双预测MPC改为短时域滚动预测候选寻优：每个控制周期评估风机转速、风阀开度和空调负荷的组合，优先选择满足预测温度/温差要求且瞬时总功率较低的组合。

## 设备分工
- WT-CPCM：通过焓状态跟踪显热/潜热缓冲，剩余潜热容量参与预测风险判断。
- 风机：在电池与环境之间具有足够温差时优先承担低功耗基础排热。
- 电动风阀：按八个等效区域温度偏差调节气流分配，优先照顾高温区。
- 空调：作为末级制冷补偿；当环境温度接近电池温度、风机换热能力不足或预测温度约束可能越限时介入，不固定常开。
- MPC：每5分钟滚动评估离散候选组合；预测时域使用界面设定的 prediction_minutes（默认20 min），并在目标温度下预留0.4℃预测安全裕度。

## 三组公平对照
- 固定送风：固定风机/风阀设置，达到高温阈值后启动空调。
- 固定阈值：根据当前温度和温差分段控制风机、风阀和空调，不使用预测信息。
- 双预测MPC：利用温度趋势、八区温度分布、环境温度、负荷倍率及PCM状态滚动优化设备组合。
三组使用相同的电池热模型、环境、设备配置和负荷工况。

## 验证
详细结果见 `three_scenario_validation_v6.csv`，包括：
- 空调设备：壁挂式7.5 kW、顶装式20 kW；
- 工况：30℃/1C、35℃/1C、30℃/1.2C、40℃/1C、45℃/1C；
- 三组总能耗、风机能耗、空调能耗、最高温度和最大温差等指标。

在本版列出的十种“空调设备×工况”组合中，双预测MPC的最终系统总能耗均低于两种对照组的较低者；各组合最大温差均控制在3℃以内。请以CSV中的实际结果为准，不要把模型输出称为实测节能率。

## 重要物理边界
当环境温度高于电池最高温度控制目标时，空冷不能将电池冷却到环境温度以下，必须依赖制冷设备；因此40℃、45℃环境下最高温度仍可能高于38℃目标。这不是控制器能够通过“少开空调”解决的，需结合空调制冷量、热负荷、风量和热耦合参数验证设备能力。
