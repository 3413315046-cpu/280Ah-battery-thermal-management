# 280Ah储能电池舱智能热管理演示平台 v2

## 文件
- `app.py`：Streamlit网页，统一深色文字、白色图表背景。
- `thermal_engine.py`：三组分区等效热模型，含焓法PCM状态。
- `requirements.txt`：运行依赖。

## 替换方式
将压缩包中的 `app.py`、`thermal_engine.py`、`requirements.txt` 分别覆盖GitHub仓库根目录同名文件，提交后等待Streamlit Cloud重新部署。

## 本版修复
1. 所有图表明确使用白色背景和深色文字，Plotly图表关闭Streamlit自动主题覆盖。
2. PCM改用焓法计算：显热阶段、相变潜热阶段和完全熔化后的显热阶段连续衔接；液相率和剩余潜热储能来自同一个状态变量。
3. PCM热交换以高温接触区为代表，避免仅用舱内平均温度导致相变状态不响应。
4. 双预测MPC采用温度趋势前馈、PCM潜热余量修正、分区冷量分配和风机优先/空调补偿策略。
5. 固定送风和固定阈值组保留独立控制逻辑；最大温差均由八个等效区域温度计算。

## 科学使用边界
该平台是简化等效热模型演示，不等同于实测、CFD或工程现场验证。热负荷、等效热容、风机系统阻力、空调制冷能力、PCM接触热阻和相变参数均需用项目真实数据标定。当前默认工况输出仅用于检查程序逻辑和展示方法，不得表述为实测结果。
