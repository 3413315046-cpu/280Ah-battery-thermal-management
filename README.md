# 280Ah电池舱智能热管理平台 v4.0

## v4.0改动
- 移除“风机功率与风速”独立栏目；
- 移除“模型依据与限制”独立栏目；
- PCM固定参数采用用户提供表格：密度1100 kg/m³，比热容1740 J/(kg·K)，导热系数3.5 W/(m·K)，相变温区38–43℃，相变潜热120 kJ/kg；
- 增加12热区降阶温度模型；
- 增加自动风机温差反馈调速，控制目标可选，默认最大温差≤3℃；
- 增加有风/无风电池平均温度对比；
- 增加PCM温度及储热状态展示；
- 高级深色界面。

## 部署
GitHub仓库根目录需有app.py、requirements.txt、README.md和data/文件夹。Streamlit Cloud使用main分支、app.py入口。

## 科研真实性说明
当前自动控制为12热区降阶工程估算，参数包括暂定电芯内阻/质量/比热、区域热源不均匀系数、空气分配系数、等效换热系数及区间混合热导，尚未通过144芯实验温度或CFD验证。控制器只能在当前降阶模型内尝试满足温差目标，不能宣称真实电池舱已保证最大温差≤3℃。风机候选参数用于相似定律估算，不是安装工作点保证。正式竞赛/论文定量结论前须以风机曲线、系统阻力、CFD和实测温度校准。
