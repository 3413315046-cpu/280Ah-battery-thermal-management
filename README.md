# 储能电池舱热管理平台 v11｜温度约束优先 + 可行域最低能耗

## 本轮修正
用户反馈的网页截图仍显示双预测MPC温度曲线高于固定送风/固定阈值。该截图与v10独立计算的输出不一致，说明此前页面未实际运行v10引擎。v11更换了引擎和缓存版本标识，页面应显示“MPC v11”。

## 控制原则
每5 min滚动预测20 min、1 h、2.5 h；依据电池分区温度、温差、PCM状态和环境温度，联合选择风机转速、风阀开度、空调负荷。默认环境30℃、初始电池30℃、目标温度38℃时，温度跟踪上限为35.85℃（即目标温度减2.15℃，并设置环境温度+1.5℃的物理下限）。在温度和温差惩罚下，再优化能耗；空调按需间歇补偿，不是固定全开。

## 默认48小时对照（30℃环境、30℃初温、1C、完整充放电循环）

v11默认48h工况下，双预测组最高温度比固定送风低0.20℃、比固定阈值低0.55℃；最大温差降低约67.6%；系统总能耗比固定阈值低约13.7%、比固定送风低约49.7%。平均温度并未最低，不能宣称平均温度也优于对照组。

## 运行时间端点验证
`three_scenario_validation_v11.csv`覆盖20、46、47、48小时三组结果；各组终点严格等于设置时长，5分钟步长，不额外外推下一步能耗。

## 重要说明
这是简化八区等效热模型的数值仿真，不是实测或CFD结果。默认工况下的改进必须在其他环境温度、倍率、负荷时序和设备规格下继续验证。模型参数仍需CFD或实验标定。不能把仿真结果描述成实际设备节能实测。
