# 280Ah电池柜智能热管理公开网站

## 当前版本
公开资料与几何基线展示版。包含用户确认的舱体/电柜/电芯/间距/PCM厚度参数、CAD审计摘要、WT-CPCM论文参数、280Ah候选电芯参考数据及公开数据源。

**注意：当前不开放真实温度预测。** 目标电芯物性、当前PCM批次密度/显热比热、界面热导、风机P-Q曲线和经审核的动态边界尚未闭合。页面不会生成虚构预测结果。

## 本地运行
```bash
pip install -r requirements.txt
streamlit run app.py
```
打开终端显示的本地地址即可预览。

## 发布为任何人可访问的网站
1. 将整个文件夹内容上传到一个GitHub仓库（公开仓库适合公开展示）。
2. 登录 Streamlit Community Cloud。
3. 选择该GitHub仓库、分支和 `app.py`。
4. 点击 Deploy，平台会生成公开 `*.streamlit.app` 地址。
5. 将生成的公开地址分享给访问者。

部署前请检查仓库中没有私人文件、密钥、未授权论文全文或敏感实验数据。当前包只包含页面所需的摘要JSON与代码。
