# 280Ah电池柜智能热管理网站 v3.0

## 本版功能
- 运行工况输入：环境温度、电池初始温度、倍率、时长；
- 有风机/无风机平均电池温度对比；
- PCM温度与净储热量估算；
- 风机数量/转速调节，估算总风量、功率、截面平均风速；
- 144芯CAD点位浏览；
- 参数来源与限制说明。

## 风机参考
ebm-papst W3G500-KK07-G2：500 mm，厂家公开最优效率工作点约4110 m³/h、82 Pa、230 W；额定最大输入约250 W，970 rpm。此型号厂家注明主要用于工业蒸发器，因此这里只作性能参考候选，不是本项目定型采购建议。
官方产品页：https://www.ebmpapst.com/us/en/products/axial-fans/p/W3G500KK07G2.html

## 计算方法与限制
集中参数模型：
- 电芯焦耳热：Q=144*(280*倍率)^2*R；
- 电芯总热容：144*m_cell*cp_cell；
- PCM几何总体积来自Stage15 v4.7.1区域映射表，质量由可调假设密度计算；
- WT-CPCM三阶段焓来自王佳论文；
- 风机相似定律估算风量、压力和功率；实际工作点受系统阻力曲线影响；
- 空冷换热用有效风量利用率折减质量流量换热能力；
- 两节点电池/PCM集中参数能量平衡。

**本版结果是方案级工程估算，不是已验证的192状态真实柜体预测，不可用于安全认证或直接采购定型。**
论文未给出PCM密度/显热比热；候选LF280K不是已确认的目标电芯型号；内阻、等效热容、风道利用率和热导需要实验/CFD校准。真实MPC闭环尚未接入。
