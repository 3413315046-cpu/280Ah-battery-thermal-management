# 280Ah储能电池舱热管理平台 v9｜温度-温差-能耗多目标MPC

## 本版核心调整
v8的目标函数仍然偏重“满足38℃约束后尽量省电”，导致双预测组温度接近控制上限，出现截图中双预测组温度高于固定送风组的情况。v9将控制目标改为多目标、分层优化：

1. **温度优先**：以预测最高温度为首要优化对象，不再把38℃附近当作期望运行点。默认30℃环境下，预测目标温度下移至约35℃量级。
2. **温差优先**：同时优化八个等效区域的温度分布，预测最大温差控制在约2℃目标内，最终运行最大温差低于3℃。
3. **能耗优化**：在温度与温差性能达到目标后，再降低风机、空调和风阀执行能耗。
4. **多时域预测**：每5分钟重新优化，联合使用20 min短期、1 h中期和2.5 h较长期预测，避免只看短时间而忽视温度长期累积。
5. **设备协同**：风机利用环境温差换热；风阀按八区温度偏差分配气流；空调作为主动补偿设备按预测需求间歇介入，不再固定开启；PCM状态持续进入控制器。
6. **环境温度适配**：预测温度目标考虑环境温度与合理换热逼近余量，避免在高环境温度下无意义地追求远低于环境温度的目标。

## 默认48小时验证
工况：环境温度30℃、初始电池温度30℃、1C、完整充放电循环、4台EC轴流500mm、壁挂式7.5kW空调。所有组别采用相同热负荷与时长。

| 指标 | 固定送风 | 固定阈值 | 双预测MPC v9 |
|---|---:|---:|---:|
| 系统总能耗 | 14.035 kWh | 8.175 kWh | **7.531 kWh** |
| 电池最高温度 | 35.90℃ | 36.25℃ | **34.87℃** |
| 平均电池温度 | 33.16℃ | 33.48℃ | 33.45℃ |
| 最大温差 | 5.78℃ | 5.79℃ | **1.87℃** |
| 风机能耗 | 13.171 kWh | 7.310 kWh | 4.245 kWh |
| 空调能耗 | 0 | 0 | 2.418 kWh |
| 风阀及辅助能耗 | 0.8640 kWh | 0.8647 kWh | 0.8683 kWh |

与能耗最低的固定阈值组相比，v9在该默认模型工况下：
- 总能耗降低约7.9%；
- 电池最高温度降低1.38℃；
- 平均电池温度降低约0.03℃；
- 最大温差降低约3.92℃。

与固定送风组相比，v9最高温度更低、最大温差显著更小、总能耗明显更低；固定送风组的平均温度略低约0.29℃，说明多目标控制仍存在温度均匀性与整体平均冷却之间的权衡，不应宣称每一项指标都绝对优于所有基准。

## 20/46/47/48小时终点连续性
`three_scenario_validation_v9.csv`逐组记录了20、46、47、48小时结果。48小时终点严格为48.000 h，576个5分钟时间步；46/47小时也分别精确终止于46.000/47.000 h，不会出现最后一步额外累计能耗。

默认30℃环境下，双预测MPC：
- 20 h：3.199 kWh；最高温度34.87℃；最大温差1.87℃。
- 46 h：7.122 kWh；最高温度34.87℃；最大温差1.87℃。
- 47 h：7.306 kWh；最高温度34.87℃；最大温差1.87℃。
- 48 h：7.531 kWh；最高温度34.87℃；最大温差1.87℃。

## 重要科研边界
本平台是简化八区等效热模型，不是实测或CFD验证结果。换热系数、热容、PCM界面换热和空调实际部分负荷效率仍需CFD/实验标定。不同控制组的温度与能耗必须联合比较；当某基准组温差超限时，不能只用其较低平均温度来判定其热管理性能更好。节能率应表述为模型仿真结果，不能写成实测节能率。

## 运行
Windows PowerShell进入解压目录：
```powershell
pip install -r requirements.txt
streamlit run app.py
```
若旧页面还在运行，先在旧终端按Ctrl+C停止，再从v9目录启动。页面顶部应显示“控制器 v9｜20 min+1 h+2.5 h多时域预测”。
