# 280Ah储能电池舱热管理平台 v10｜温度优先双预测MPC

## 本版针对的问题
用户截图中双预测组最高温度和平均温度均高于两组基准，说明此前温度目标设置偏松/运行页面未体现目标。v10将默认控制器切换为温度优先策略，明确将温度跟踪目标设为34.5℃（环境温度较高时使用环境温度+1.5℃下限），并保留八区温差优化；设备能耗作为后续优化项。

每5分钟重算风机、风阀、空调组合，预测时域为20 min、1 h、2.5 h。空调按预测需求间歇投入，不是固定开启。风机优先承担可由环境温差实现的换热，风阀向偏热区域分配更多气流，PCM状态继续进入控制计算。

## 默认48小时结果
工况：环境30℃、初始电池30℃、1C、完整充放电循环、4台EC轴流500mm、壁挂式7.5kW空调。

| 指标 | 固定送风 | 固定阈值 | 双预测MPC v10 |
|---|---:|---:|---:|
| 最高温度 | 35.90℃ | 36.25℃ | **34.35℃** |
| 平均温度 | 33.16℃ | 33.48℃ | **32.86℃** |
| 最大温差 | 5.78℃ | 5.79℃ | **1.87℃** |
| 系统总能耗 | 14.035 kWh | **8.175 kWh** | 10.292 kWh |
| 风机能耗 | 13.171 kWh | 7.310 kWh | 6.080 kWh |
| 空调能耗 | 0 | 0 | 3.346 kWh |

v10实现了双预测组的最高温度、平均温度、最大温差三项最低；但总能耗仍高于固定阈值组约25.9%，低于固定送风组约26.6%。这反映了温度优先运行的额外制冷代价。不能把v10宣传为能耗也最低；如需同时达到能耗最低，需要进一步优化设备效率/容量参数、控制策略，并在同等温度约束下比较。

## 重要边界
以上是简化八区等效热模型仿真，不是实测或CFD结果。参数需要通过真实设备曲线、CFD及实验标定。对外报告必须保留模型仿真属性，不可写成实测节能率。
