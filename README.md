# 280Ah储能电池舱智能热管理演示平台 v3（风机+风阀，无空调）

## 本版策略调整
- 按当前中车杯方案取消空调，三组对照均只使用相同规格的EC风机和电动风阀。
- 固定送风组：固定风机转速、固定风阀开度。
- 固定阈值组：按当前最高温度和温差分段调节风机、风阀，不使用未来预测。
- 双预测MPC组：利用温度趋势、负荷前馈、PCM潜热余量和分区温差滚动调节风机转速与风阀开度。
- 风机空冷换热采用有效换热系数0.00012，并将可用风冷换热上限设为当前热负荷；该系数是等效模型参数，必须用Fluent结果或实验数据标定，不能当作已验证的实测换热系数。
- 页面移除空调配置、空调能耗、空调控制曲线和空调参数库。
- 能耗节省率按双预测MPC相对于两组基准中能耗较低的一组计算，避免只挑选较高能耗基准。

## 默认工况（环境30℃、初始30℃、1C、48h）
以 `default_48h_model_check.csv` 为准。当前模型计算结果用于程序逻辑与策略演示，不是实测或CFD验证结果。

## 运行
安装依赖：
`pip install -r requirements.txt`

启动：
`streamlit run app.py`

## 后续标定
应通过Fluent获得风机工作点/舱内流量分配/电池表面对流换热系数，并用实验温度曲线校准热负荷、热容和PCM接触换热参数。不同环境温度与倍率下，MPC未必在所有工况都具有最低能耗；控制策略应以温度和温差约束满足为前提，再优化能耗。
