# 280Ah储能电池舱热管理演示平台 v4（保留空调的双预测MPC优化版）

## 本版控制方案
保留EC风机、空调、电动风阀三类执行设备，三组对照使用相同设备配置。

1. 固定送风组：风机固定转速、风阀固定开度；最高温度达到40℃后启用空调。
2. 固定阈值组：依据当前最高温度和温差分段调节风机、空调与风阀，不使用预测信息。
3. 双预测MPC组：依据温度趋势、环境温度、负荷倍率、PCM液相率/潜热余量及分区温差进行滚动调节。风机承担基础排热，预测风险升高时调用空调辅助制冷，风机与空调均有限幅和变化率约束。

## 默认参数下的控制规律
- 风机指令：由基础风量、环境温度补偿、负荷倍率补偿、预测温度风险和温差风险共同决定。
- 空调指令：预测风险超过预警阈值后逐步增加，最大负荷比例限制为0.25。
- 风阀：随分区温差增加而开大，优先改善区域温度均匀性。

## 三组工况验证（48 h）
详见 `three_scenario_validation_v4.csv`：
- 默认工况：环境30℃、1C；
- 高温工况：环境35℃、1C；
- 高负荷工况：环境30℃、1.2C。

在上述三组模型工况下，双预测MPC系统总能耗均低于固定送风组和固定阈值组，且最大温差均小于3℃。双预测MPC三组工况均实际调用空调。

## 重要说明
这些数值是当前简化分区热模型的仿真输出，不是实测数据，也不是CFD验证结果。风机换热系数、空调制冷量折减系数、负荷热源和PCM耦合参数必须通过Fluent仿真或实验标定。不能据此宣称所有环境温度、倍率和电池舱结构下都必然节能。
