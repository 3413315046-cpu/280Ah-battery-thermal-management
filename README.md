# 280Ah储能电池舱预测调控平台 v6.0

## 本轮用户设备参数已接入
- EC轴流500mm：4500m³/h、350Pa、200W、0–1800rpm；采用用户给定P-Q离散点。
- EC离心355mm：1800m³/h、1442Pa、500W、0–2600rpm；采用用户给定P-Q离散点。
- 壁挂式7.5kW空调：制冷输入3.2kW、内风量2000m³/h、EER 2.34。
- 顶装变频20kW空调：额定输入9.1kW，30/40/50/60Hz制冷量12/15/20/22kW，内风量6000m³/h。
- 小型DC风扇8038：5W、130m³/h；6025：3.24W、67.9m³/h。
- 400×300电动风阀：有效面积0.10m²、执行器5W，ζ随开度离散点插值。
- 控制阈值按用户给定温度/消防/故障逻辑配置。
- 风机功率按立方相似律，空调变频输入功率按P_rated*(f/f_rated)^1.5，累计能耗按ΣPΔt。
- 风机P-Q曲线和风阀阻力共同用于估算风机工作点。

## 说明
当前热模型仍为12热区集中参数降阶模型。用户提供的设备额定参数与离散曲线已经写入；但风道系统阻力曲线、并联风机实际相互作用、空调实际部分负荷性能、热源分布、风口分区对应关系及控制器权重尚未通过实测/CFD校准。当前页面输出用于方案演示与参数研究，不能视为设备厂家保证值、真实舱体性能或安全认证结论。
消防联锁按给定逻辑实施；“风机停机或排风模式”当前选用停机。备用风机实际容量和切换电路尚未给出，故障逻辑仅作为报警/降级策略展示，不模拟已验证的备用切换。


## v6.2 温度计算修复
- 修正空调冷量施加方式：冷量经等效UA折算后进入电池热区，不再直接将整机额定制冷量注入电芯节点。
- 空调仅在电池平均温度高于自适应控制目标时提供冷却。
- 电池与PCM温度增加0℃数值下限，图表Y轴从0起显示。
- UA暂设220 W/K，仅为待标定模型参数，不代表真实设备换热能力。
- 若结果触及0℃下限，应视为模型参数/边界条件异常信号，不能把裁剪后的曲线当成已验证预测结果。
